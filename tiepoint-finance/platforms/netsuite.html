Technical considerations

What matters in a NetSuite project.

The specifics we look at early, because they decide how clean the data will be. Product details change, so we confirm them against the vendor's current documentation during discovery.

OneWorld subsidiaries

NetSuite OneWorld supports a hierarchy of subsidiaries, each with its own base currency, rolled up for consolidated reporting. Getting that hierarchy right drives everything downstream.

Consolidated exchange rates

NetSuite keeps consolidated exchange rates by rate type (current, average and historical) for translating subsidiaries. We check they are complete and match your policy each period.

Segments

Department, class and location, plus any custom segments, carry the analysis your reports need. We confirm they are used consistently across subsidiaries.

Saved searches and SuiteAnalytics

Saved searches suit lists and exports; SuiteAnalytics Workbook suits pivots and analysis. We choose per report and record why.

Pitfalls

Common problems, and how we avoid them.

These come up in NetSuite projects regardless of who runs them.

Inconsistent segment use across subsidiaries

We review segment usage before mapping so analysis lines up across the group.

Intercompany posted one-sided

We test intercompany matching before relying on eliminations.

Saved searches nobody can maintain

We document each search we build and keep the count small.

Before release

Every NetSuite report passes five checks.

The same tie-out standard applies on every platform, for every entity and month in scope.

CheckWhy it mattersPass condition
  1. 01

    Every GL account is mapped exactly once

    Reports only add up if each ledger account lands in one reporting line, once.

    unmapped = 0
  2. 02

    Totals tie to the trial balance

    The trial balance is the agreed source of truth, so every entity and every month is compared against it.

    variance = 0.00
  3. 03

    Intercompany nets to zero

    A group should not report trading with itself. After eliminations, intercompany balances must cancel.

    IC net = 0.00
  4. 04

    Correct FX rates and periods

    Translation uses different rate types for different balances, and each month needs its own rates.

    rates = policy
  5. 05

    Large movements are explained

    A number can tie to the ledger and still mislead. Big swings need a reason before a board sees them.

    unexplained = 0
